# Correction checklist

When a rerun moves a published number, the fix is not done until the new
number is consistent everywhere it appears. Work this list in order; each step
names what to grep for the OLD number.

1. **The script.** Fix the computation (or the bug in it) in the analysis
   runner, e.g. `analysis/calibration_set_size.py`.
   Grep: `grep -rn "<old figure>" analysis/`.

2. **The machine-readable stats.** Regenerate the experiment's committed JSON
   artifact with the script itself, e.g.
   `python3 analysis/calibration_set_size.py --draws 40 --json
   analysis/calibration_set_size.json`.
   The JSON is the single source of truth for derived figures; never hand-edit
   it. Grep: `grep -rn "<old figure>" analysis/*.json`.
   One artifact per experiment, not one repo-wide file: per-experiment JSONs
   keep provenance and regeneration local to the runner that produced them,
   and they already exist (`calibration_set_size.json`, `circularity.json`).

3. **The prose tables.** Update every table row that quotes the figure, using
   the script's derivation function (e.g.
   `analysis.calibration_set_size.headline_figures`), not mental arithmetic.
   Grep: `grep -rn "<old figure>" analysis/*.md docs/ README.md`.
   `tests/test_result_consistency.py` fails if a table cell disagrees with a
   fresh rerun -- run it before committing.

4. **The README.** The top-level summary quotes headline figures (e.g. the
   "cuts ECE 62%" bullet). Same grep as step 3.

5. **The ledger.** `docs/claims-audit.md` rows cite figures as evidence
   (e.g. row 23, "62% held-out reduction at 50"). Update the figure AND the
   verdict wording if the correction changed what the evidence supports.
   Grep: `grep -n "<old figure>" docs/claims-audit.md`.

6. **Docstrings.** Module and function docstrings that quote the old number
   (e.g. the sweep's own docstring describing the 74% it set out to check).
   Grep: `grep -rn "<old figure>" --include="*.py" analysis/ lab/ jevlab/`.

7. **The tests.** Run the full suite (`python -m pytest -q`). Pinned-figure
   tests (`tests/test_result_consistency.py`, `tests/test_transfer.py`) fail
   on stale numbers by design. If a rerun legitimately moved a pinned figure,
   regenerate the JSON (step 2), update the prose (steps 3-6), and record why
   in the test's docstring -- never just loosen the assertion.

Done means: the JSON regenerated by the script, the prose quoting it,
`tests/test_result_consistency.py` green, and the full suite green.
